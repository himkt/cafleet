GOAL: Move the CLI's global options (--fleet-id, and decide --json) from the top-level `cafleet` click group onto the individual child subcommands. Motivation is ergonomics: requiring --fleet-id BEFORE the subcommand confuses users. --agent-id is already a per-subcommand option, so this aligns --fleet-id with that existing convention.

KEY CONSTRAINT THE DOC MUST ADDRESS HEAD-ON: the current global placement is DELIBERATE. Per docs/spec/cli-options.md (Option Source Matrix line 72 + the "Why --fleet-id is a literal flag" callout line 54), --fleet-id sits immediately after `cafleet` so a SINGLE permissions.allow pattern `cafleet --fleet-id <id> *` covers every subcommand for that fleet, and it is silently accepted/ignored on subcommands that do not need it.
