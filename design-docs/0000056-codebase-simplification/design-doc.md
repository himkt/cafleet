# Codebase Simplification

**Status**: Approved
**Progress**: 73/91 tasks complete
**Last Updated**: 2026-05-13

## Overview

A comprehensive behavior-preserving simplification sweep across the CAFleet repository, identified by ten parallel Researcher teammates working in disjoint subsystem slices and reconciled into a five-PR phased plan. Removes dead code, consolidates duplicated helpers, fixes stale skill/doc text, and trims redundant tooling. CLI surface, database schema, message-envelope JSON, admin WebUI rendered DOM, Alembic migrations, design-doc content, and exit-code behavior are unchanged.

## Success Criteria

- [ ] Every finding row in the **Specification** tables is either implemented or marked `skipped` with a one-line rationale committed in the implementing PR description.
- [ ] After each of the five PRs lands, `mise //cafleet:test`, `mise //cafleet:lint`, `mise //cafleet:format`, `mise //cafleet:typecheck`, and `mise //admin:lint` all pass.
- [ ] Each PR step records a **pre-PR smoke baseline** (Step `0` in every PR) by running the CLI happy-path on the current branch's parent commit and capturing stdout/stderr to `/tmp/baseline-pr<N>.txt`. After the PR's code edits land, re-run the same happy-path and diff against the baseline file; the diff is accepted only when every line that differs is a timestamp (`\d{4}-\d{2}-\d{2}T…`) or UUID (`[0-9a-f]{8}-…`). Any other delta blocks the PR.
- [ ] Zero changes to: the `cafleet` CLI command/flag surface, Alembic migration files, `agent_card_json` shape, `tasks` columns, message-envelope JSON shape, design-doc `.md` content outside this folder, the four other Status: Complete design docs, and the admin WebUI rendered DOM / CSS class strings / network endpoints.
- [ ] Zero new code comments justifying removals (per `~/.claude/rules/removal.md` — git history and this design doc are the historical record).
- [ ] One conflict surfaced for user resolution (the **CLAUDE.md duplication** item; see § Specification > Findings considered and explicitly skipped).
