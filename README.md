# CAFleet

https://github.com/user-attachments/assets/bd2b195a-f3de-4fa3-bcc8-3c6ef9f1016a

CAFleet multiplexes independent coding-agent sessions in tmux or herdr and coordinates them through durable messages. Use its CLI and skills for delegated research, implementation and review. The Director receives full durable replies through native inbox tools and reviews observed results.

## Install

```bash
brew install himkt/tap/cafleet
```

```bash
cafleet setup
```

Alternatively, extract the single binary for your platform from [GitHub Releases](https://github.com/himkt/cafleet/releases) onto PATH and run setup. See [Quickstart](https://himkt.github.io/cafleet/quickstart) for configuration and trust.
