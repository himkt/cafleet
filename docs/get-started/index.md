# Get Started

This section walks first-time users and contributors through everything needed
to run, configure, and contribute to CAFleet. Start with **Install** if you are
new to the project, or jump straight to **Configure** if the CLI is already on
your machine.

- [Install](install.md) — install the `cafleet` CLI and the coding-agent
  plugins (`claude`, `codex`, `opencode`).
- [Configure](configure.md) — recommended `permissions.allow` blocks and other
  per-coding-agent settings.
- [Quickstart](quickstart.md) — one-screen walkthrough that creates a session,
  spawns two members, and sends a message between them.
- [Contributing](contributing.md) — project layout, local development loop, and
  the design-doc-driven contribution flow.
